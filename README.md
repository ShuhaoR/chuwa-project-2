# Chuwa Project 2 – HR Management System

## 🧾 Overview
This is a full-stack **HR management platform** built as part of the Chuwa America fullstack training. It allows HR staff to register employees, manage onboarding tokens, and review document submissions.

I developed the entire **HR frontend** module, focusing on UI, Redux Toolkit integration, and backend API connections.

## 🔧 Tech Stack
- **Frontend**: React, Redux Toolkit, React Router, Vite
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Authentication**: JWT
- **Dev Tools**: Postman, Git, VSCode

## 💡 My Contributions
- Built HR dashboard layout and components
- Implemented `RegisterToken`, `EmployeeList`, and `DocumentReview`
- Integrated Redux Toolkit for global state and async thunks
- Connected frontend to backend API
- Designed protected routes and error handling

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/yourusername/chuwa-project-2.git
cd chuwa-project-2
```

### 2. Install Backend Dependencies
```bash
cd Backend
npm install
```

### 3. Install Frontend Dependencies
```bash
cd ../Frontend/employee-management
npm install
```

### 4. Start the Backend
```bash
cd ../../../Backend
npm run server
```

### 5. Start the Frontend
```bash
cd ../Frontend/employee-management
npm run dev
```

> Frontend: `http://localhost:5173`  
> Backend: `http://localhost:5400`
